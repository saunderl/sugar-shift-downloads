# Sugar Shift — Android downloads

Native C#/.NET MAUI whole-line match-3 puzzle. Shift rows and columns, trigger cascades, rotate the board, and unlock special gems.

[Download Sugar Shift 0.2.0 APK](https://github.com/saunderl/sugar-shift-downloads/releases/download/v0.2.0/SugarShift-0.2.0.apk)

Open this link on your Android phone, download the APK, then open it to install. If prompted, allow installation from the app you used to open the APK.

Requires Android 6.0+ and ARM64 (or an x86-64 emulator). Offline play. Prototype signed with a development certificate; not a Play Store release.

This repository contains installation information and APK releases only. Game source and signing keys are not published here.
Specials now match their own color. Match 4 for a bomb or 5+ for a board wipe. Install over the previous APK to retain progress.
